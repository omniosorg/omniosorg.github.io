OmniOSce v11 r151060 is out!

On the 2nd of November 2026, the OmniOSce Association has released a new stable
version of OmniOS - The Open Source Enterprise Server OS. The release comes
with many tool updates, brand-new features and additional hardware support. For
details see the [release notes](https://omnios.org/rn/r60).

Highlights include:

* Significant performance improvements in the IPS packaging system - `pkg`
  starts faster, uses far less memory, installs and removes packages in a
  fraction of the time, and the dependency solver now explains concisely why
  an operation cannot be satisfied. Run `pkg update-format` after upgrading
  to convert existing images to the new format and benefit fully;
* NFSv4.1 delegations in the NFS server, and SMB 3.1.1 support in the SMB
  client;
* `posix_spawn()` is now implemented in the kernel and is significantly
  faster;
* multiple queue pairs and event index support for virtio networking,
  improving network performance in virtual machines, along with IPv6 TSO
  offload and other improvements for bhyve guests;
* the new `zpool wait` command;
* address space layout randomisation (ASLR) enabled by default on new
  installations;
* OpenSSH 10.6p1 - check the release notes for changes in behaviour which
  may affect existing configurations.

**Note that r151056 is now end-of-life.** You should upgrade to r151058
or r151060 to stay on a supported track. r151054 is a long-term-supported (LTS)
release with support until May 2028.

OmniOS is fully Open Source and free. Nevertheless, it takes a lot of time and
money to keep maintaining a full-blown operating system distribution. Our
statistics show that there are almost 2'000 active installations of OmniOS
while fewer than 20 people send regular contributions. If your organisation
uses OmniOS based servers, please consider becoming a regular
[patron](https://omnios.org/patron) or taking out a
[support contract](https://omnios.org/invoice).
